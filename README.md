# SimpleCrud (.NET Console)

SimpleCrud é uma aplicação de **gerenciamento de produtos** em **.NET**, executada no **console**, criada com o objetivo de praticar **Programação Orientada a Objetos (POO)**, manipulação de listas em memória e a estrutura de padrão de projeto com separação de responsabilidades (Models, Repositories e Views).

## 🛠️ Tecnologias utilizadas

*   C# (.NET)
*   Console Application


## 📌 Funcionalidades

*   Cadastrar um novo produto (Nome e Preço)
*   Listar todos os produtos cadastrados
*   Editar informações de um produto existente
*   Remover produtos do sistema
*   Atribuição automática de IDs

## 🧱 Estrutura do Projeto

```text
simple-crud-dotnet
├── Models
│   └── Product.cs
├── Repositories
│   └── ProductRepository.cs
├── Views
│   └── ProductView.cs
└── Program.cs
```

## 🚀 Como executar o projeto

### Pré-requisitos

*   SDK do **.NET 6.0 ou superior**
*   IDE (Visual Studio ou VS Code)

### Passos

1.  Clone o repositório:
    
    ```shell
    git clone https://github.com/Gabriel-afk-9/simple-crud-dotnet.git
    ```
    
2.  Navegue até a pasta do projeto:
    
    ```shell
    cd simple-crud-dotnet
    ```
    
3.  Execute o projeto:
    
    ```shell
    dotnet run
    ```
